Machine Learning (ML)

Machine Learning enables computers to learn from data without explicit programming, improving automatically through experience.

Supervised Learning

Labeled Data

Models learn from labeled input-output pairs to predict outcomes.

Tech: Linear Regression, SVM, Random Forest

Unsupervised Learning

Unlabeled Data

Finds hidden patterns in data without labeled responses.

Tech: K-Means, PCA, DBSCAN
Use: Customer Segmentation, Anomaly Detection

Reinforcement Learning

Reward Based

Agent learns by interacting with environment to maximize rewards.

Tech: Q-Learning, DQN, Policy Gradients
Use: Game Playing, Robotics, Navigation
